# 🎮 Hangman

Консольная игра **«Виселица»**, написанная на Java.

Игроку загадывается случайное слово, после чего он должен отгадать его, вводя буквы по одной. За неправильные попытки постепенно строится изображение виселицы. Игра заканчивается победой при полном угадывании слова или поражением при достижении максимального количества ошибок.

Проект выполнен в рамках изучения Java и практики разработки небольших приложений.

## 📌 Функциональность

* Запуск новой игры или выход из приложения.
* Случайный выбор слова из файла со словарём.
* Отображение текущего состояния загаданного слова.
* Ввод букв пользователем.
* Проверка корректности введённых символов.
* Подсчёт ошибок.
* Отображение состояния виселицы в консоли с помощью ASCII-символов.
* Определение победы или поражения.
* Возможность начать новую игру после завершения предыдущей.

## 🎯 Правила игры

После запуска необходимо выбрать:

```text
N — начать новую игру
E — выйти из приложения
```

После начала игры программа загадывает случайное слово.

Игрок вводит буквы по одной:

* если буква есть в слове — она открывается;
* если буквы нет — увеличивается количество ошибок;
* после каждой попытки отображается текущее состояние слова и виселицы.

Игра завершается, когда слово полностью отгадано или количество ошибок достигает допустимого максимума.

В процессе разработки были отработаны:

* работа с классами и объектами;

* коллекции;
* работа со строками;
* циклы и условные конструкции;
* работа с файлами;

* декомпозиция программы на отдельные классы и методы;
* работа с Git.
